# BookVault Pro 📚

A professional book review and library management platform built with vanilla JavaScript, CSS, and HTML.

## 🌟 Features

- **Smart Library Management** - Add, edit, delete, and organize your books
- **Advanced Search & Filters** - Find books by title, author, genre, rating, or status
- **Reading Progress Tracking** - Track your reading goals and progress
- **Dark/Light Mode** - Professional theme switching
- **Export/Import** - Backup and restore your library data
- **Interactive Rating System** - 5-star rating with hover effects
- **Responsive Design** - Perfect on desktop, tablet, and mobile
- **PWA Support** - Installable as a native app
- **Offline Capability** - Works without internet connection

## 🚀 Live Demo

Visit the live application: [BookVault Pro](https://your-netlify-url.netlify.app)

## 📱 Installation

### As a Web App
1. Visit the live URL
2. Click "Install App" in your browser
3. Use like a native application

### Local Development
1. Clone or download this repository
2. Open `index.html` in your browser
3. Start managing your book library!

## 💾 Data Storage

- All data is stored locally in your browser
- Use Export/Import features to backup your library
- No server required - completely client-side

## 🛠️ Technologies Used

- **Frontend**: HTML5, CSS3, Vanilla JavaScript (ES6+)
- **PWA**: Service Workers, Web App Manifest
- **Storage**: LocalStorage API
- **Styling**: CSS Custom Properties, Flexbox, Grid
- **Fonts**: Inter (Google Fonts)

## 📊 Browser Support

- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+

## 🔧 Development

No build process required! Simply edit the files and refresh your browser.
