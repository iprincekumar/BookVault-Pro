## ✨ Features

- **Add books to your library** with title, author, genre, reading status, cover image, page count, a 1–5 star rating and a written review (up to 500 characters)
- **12 genres**, including Fiction, Mystery, Sci-Fi, Fantasy, Biography, Self Help and Business
- **Reading status tracking**: Completed, Currently Reading, or Want to Read
- **Search, filter and sort** by genre, rating and status; sort by date, title, author or rating
- **Grid and list views** with pagination
- **Stats dashboard** showing total books, average rating, reading-goal progress and your top genre
- **Yearly reading goals** (12, 24 or 52 books)
- **Dark mode** toggle
- **Import and export** your library data
- **Responsive and mobile-friendly** design

## 🚀 Getting Started

Try it instantly at **[bookvaultpro.netlify.app](https://bookvaultpro.netlify.app)**, or run it locally:

```bash
git clone https://github.com/iprincekumar/BookVault-Pro.git
cd BookVault-Pro
```

Then open `index.html` with a local server, such as the **Live Server** extension in VS Code.
